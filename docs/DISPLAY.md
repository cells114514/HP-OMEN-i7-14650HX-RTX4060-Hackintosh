# 内屏背光与 HiDPI

本机NVIDIA系统驱动为 [NullMoth 2.5.3](https://github.com/nullmoth/nvidia-macos-driver/releases/tag/v2.5.3)。它不在 EFI 中，不能只复制 EFI 就获得显卡加速；请按上游说明单独安装匹配版本，不由本仓库自动更换。

`nvrmacpibl=1` 使本机内屏实际背光可调。原 ACPI GPU 节点提供 NBCI 路径；这与仅覆盖一个通用PNLF并不等价。这个开关在某些其他笔记本可能不能使用，保留备用启动入口。

`nvfbhidpi=1` 配合显示覆盖表及系统模式选择，当前日用为逻辑1600×900、渲染3200×1800、面板2560×1440@60Hz。系统已永久保存，不需要BetterDisplay Pro虚拟屏幕常驻，也未安装登录脚本。

同一内屏原生2560×1440@240可用；不代表大尺寸HiDPI@240可用。部分较低尺寸曾成功，1600×900到1920×1080以及后续1440×810/1536×864补测未成功。有效时序只枚举60和240，不能从EDID纵向范围推断中间刷新率。

`DisplayProductID-b7d.sample.plist` 是本机排查过程中保留的显示覆盖**参考样例**，已去除EDID序列号，并不保证与最终机器缓存/显示设置完全相同。不自动安装到系统，不包含WindowServer个人偏好。先按上游文档建立自己的覆盖表，再选择已存在的模式。

`set-hidpi-1600x900.rb` 是本机已用的模式选择代码，依赖私有CGS接口及BOE vendor/product匹配。必须在声明 `NSHighResolutionCapable=true` 的进程内运行，普通低分辨率解释器直接执行可能失败；构造高分辨率启动器的说明见构建文档。测试前保存工作并退出虚拟屏幕镜像；脚本只选择已有模式，不创造自定义时序。
